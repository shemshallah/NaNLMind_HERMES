# Rounds 010–011 synthesis

This records what changed after the external Round 010/011 results, and what
Hermes does **not** claim.

## 1. Quantum controls

- CPU simulations reproduce Bell-state CHSH `2.828427`, entropy 1 bit,
  two-path interference 1/0/0.5, and SU(2) loop-trace invariance.
- These are exact classical calculations. They do not demonstrate physical
  quantum behavior in NaN memory, entanglement, or a quantum advantage.
- The useful part is the gauge-invariant loop observable, which is ordinary
  matrix algebra and can be used in a classical model.

## 2. Directional relations

Round 009 reported a directional AUC gain (+0.0538). Round 010's six-seed,
equal-parameter replication found:

| model | mean held-out AUC |
|---|---:|
| cosine | 0.65117 |
| symmetric bilinear | 0.66568 |
| ordered bilinear | 0.66462 |

The ordered model was **0.00106 below symmetric**; positive direction was
preferred only 59.4% of the time. The directional advantage is therefore not
established. Any new operator model must beat an equal-parameter symmetric
control, not just cosine similarity.

## 3. Phase memory

Round 011:

- 64 prototypes × 64 phase components × 3,000 queries: gauge-invariant
  retrieval 100%, naive phase-sensitive retrieval 41.37%.
- A 128-channel real cosine/sine implementation agreed on all 3,000
  predictions.
- Independent phase noise destroys recall; at 32 components, 1,024 patterns,
  σ=2.0 rad was near chance.
- Encoding a 68.09% text classifier's probabilities as phases changed nothing.

Hermes implements this as `nanlmind_hermes/phase_memory.py` and documents the
noise limits in `docs/PHASE_MEMORY.md`. It is a memory mechanism, not quantum
computation.

## 4. NaN palindrome audit

Round 010 generated 10,256 strict IEEE-754 palindrome NaN samples across four
sign/quiet classes. The raw namespace is large, but this is encoding capacity,
not addressable RAM or quantum state space. Hermes keeps the NaN16 route and
palindrome tests separate from semantic claims.

## 5. Decisions carried into Hermes

- Use real sine/cosine channels for gauge-invariant memory; complex arithmetic
  is convenient notation, not a physical requirement.
- Keep phase coherence as an engineering constraint; do not claim quantum
  effects.
- Use typed WordNet edges (`docs/WORDNET_TYPED.md`) as the knowledge substrate.
- Keep the complete NaN pair/cycle space as the computational substrate, but
  do not equate its cycle rank with WordNet taxonomy loops.
- Next: learned edge operators with composition constraints only where the
  relation semantics justify them; matched cycle-off baseline; new-word
  definition inference and a decoder.
