# Round 042 research log and honest counterevidence

1. Inspected Round 041's native code, learned three-scalar reasoner, and role-copy decoder, and Round 039's poor-fluency subword GRU. Identified supplied proof-status token as a shortcut preventing generator loss from training the reasoning interface.
2. Built `dynamic_joint.py`: WordNet-derived 2-to-4-hop true and hard-negative episodes; the hard negatives replace an indispensable edge with another grammatical edge, keeping statement counts comparable. Learned phrase writer outputs forward/inverse/irrelevant probabilities, native triangle setter writes signed relational coefficients, native root provides actual readouts, differentiable propagation produces a continuous conditioning vector, and a learned autoregressive decoder generates words and source/destination role copies.
3. An initial train run with easy negatives was replaced by the matched-edge-count task. A five-hop indexing error (six versus eight head positions per episode) was corrected before final evaluation. Three completed 650-step seeds produced 540/540 source-split answers and 525/540 unseen five-hop answers. The conventional signed adjacency model ties both results.
4. `causal_audit.py` verifies deletion of one physical pair before read, answer change, restoration, unchanged outputs under gauge and head-index permutation. Language cross-entropy alone generates measurable nonzero gradients to writer and propagation weights.
5. A deliberately harder objective with **only token cross entropy** collapsed to abstention on all examples at 1,000 steps. Crucially, an earlier scoring heuristic mistakenly accepted the phrase 'do not support that conclusion' as positive when it contained the word `conclusion`. That produced a bogus 180/180. Fixed evaluator excludes abstentions from positive claims; the actual score is **90/180** (all negatives correct, no positives). Original erroneous report retained separately as `language_only_original_incorrect.json`.
6. Implemented persistent interactive universe backed by native root snapshots and JSON concept registry. Tested teaching new statements, cross-fact inference, gauge shift, deletion/restoration, and reload. A live-demo parser bug (`belongs to the category`) was found and corrected.
7. Implemented a separate native evidence lane for explicit taxonomic refutation. It does not overwrite a supporting path. Trained three autoregressive four-state speakers across real WordNet lemma names, each 160/160 category-correct and output-stable after gauge, but with restricted grammar and constructed refutation markers.
8. Implemented supervised few-shot writer adaptation to three unseen relation phrases with 160 gradient updates plus rehearsal of existing phrase examples. New phrase classification 1/3 → 3/3; old 16/16 unchanged; 180/180 source-split QA using new phrases, before and after gauge. This is vocabulary learning with labels, not spontaneous open-domain understanding.
9. Retrained a capacity-matched conventional-memory model at the same learning rate, seeds, training budget and examples. All three conventional models matched native results. The clean-input accuracy advantage of the NaN geometry remains **unproven**.
10. Release smoke test passed. Archive includes native source, 3 joint models, 3 conventional models, 3 four-state speakers, 1 adapted writer, 1 language-only failed model, compact WordNet corpus, an example saved universe, numerical outputs, provenance log, and SHA-256 manifest.
