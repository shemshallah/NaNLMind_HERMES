# NaN Recursive Learning — Round 037: prose-to-memory, compositional queries, retention

## Research status

**Working integrated controlled benchmark, not a full natural-language-trained generative model.** This package demonstrates neural supervised relationship *predicate* extraction from paraphrased natural-language facts derived from real WordNet 3.1 ancestry chains; native geometric storage; exact graph-based multi-hop composition; writer adaptation and knowledge retention; a previously trained autoregressive decoder consuming independently stored evidence; and matched conventional-memory controls. All comparisons use identical graph facts and graph-traversal logic. No unique NaN-specific learning advantage has been established.

## What's actually learned and what is still supplied

1. `experiment.py`: a bidirectional GRU writer learns whether a synthetic prose sentence expresses forward subtype, reverse subtype, negated subtype, or uncertain subtype. Sentence relation words are learned, but **entity boundaries and identities are explicitly supplied** and normalized to `entitya`/`entityb`. Ten authored paraphrase patterns are used for training; two others are held out. There is no unsupervised extraction from raw WordNet glosses.
2. It stores learned WordNet-derived edges in a **real native 8 MiB root**: 256 heads, 32,640 mirrored pair slots, 32-bit float lane values. The storage map uses anchored triangle circulations; edges are resolved by a conventional in-memory name index to limit slow searches. The same keys/facts also enter a matching conventional-memory baseline.
3. A **deterministic graph traversal** finds evidence for two- and three-hop ancestry. This is *not* a learned arbitrary-depth reasoning model. The question answering algorithm is exactly identical in both backends.
4. The writer receives 100 more training updates on different sentence patterns. Afterward, 80 new unseen WordNet concept chains are ingested; the original 400 queries and the additional 80 are measured for each seed, with no replay or rewrite of the previously stored edges. Preserving explicit facts is not proof of a neural model avoiding catastrophic forgetting.
5. `generation_audit.py` reuses the genuine autoregressive neural checkpoint trained in Round 036 (`robust_29.pt`) and feeds it language evidence **retrieved byte-by-byte from native pair triangles**, not a separate Python mirror feature array. Entity names remain slots; the output is generated by a trained decoder but it is **not fully unrestricted text generation**. The decoder is not retrained jointly with the new writer. The matched conventional source index has identical evidence.
6. Some prompt grammar is synthetic, some relation types are excluded from the actual chain benchmark, and there are no open-world evaluation results. The test uses true WordNet hypernym *identities* as its underlying evidence, not naturally written corpus extraction.

The initial implementation ran at only about 71% because a reverse-language predicate was erroneously written with unreversed argument positions. That genuine bug was fixed and the entire experiment rerun. The final executable sources and `run.log` reflect the corrected version.

## Reproduce

From this folder (requires Python, numpy, pytorch, a C++20 compiler, and WordNet 3.1 dict zip):

```bash
python experiment.py --wordnet /path/to/wn3.1.dict.zip --limit 200
python generation_audit.py
python test_native.py
```

`generation_audit.py` currently assumes WordNet is at `/mnt/data/wn3.1.dict.zip`; adjust that line for standalone reproduction. A prior-round pretrained checkpoint is included. `seq2seq_reference.py` is the Round036 decoder definition (not retrained here). `results.json`, `generation_results.json`, `run.log`, `native_tests.log`, `writer_*.pt`, `root_*.bin` contain the executed experiments and checkpoints. `SHA256SUMS` provides checksums. Note these snapshots are experimental host-format files; they aren't hardened against partial writes or crashes.

## What this does not demonstrate

No demonstrated accuracy advantage over equally informed conventional retrieval. No native hyperedge gradient training in this integration. No end-to-end learned relation-writer/geometry/decoder optimization. No open-ended multi-paragraph language synthesis, unknown-grammar extraction, continual neural weights memory retention across tasks, or proof of robust general-purpose inference. A real next test must use naturally occurring unrestricted prose, distant supervision or annotated relations, model-produced entity extraction, a jointly trained byte/subword decoder, and a same-capacity conventional graph with matching gauge-invariant controls.

## Key falsifiable next experiment

Train two models with matched parameters and identical unseen prose and source spans. One reads content-addressed, typed geometric relational states with cycle/holonomy interactions; the other reads an ordinary attention graph with the same facts and number of scalar states. Train jointly for next-token loss plus weakly supervised typed-edge prediction, evaluate held-out natural WordNet glosses, adversarial false premises, 2–5 hop reasoning, and 500+ token intervening noise. Gauge perturbation should be an explicit stress-test dimension, not the only win condition.
